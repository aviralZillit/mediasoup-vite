🔧 Available API Endpoints

📞 Call Monitoring APIs

  • GET /dashboard/calls Main call monitoring dashboard (HTML)
  • GET /dashboard/calls/overview Active calls and live rooms overview
  • GET /dashboard/calls/history Call history with filtering (?limit=20&status=ended)
  • GET /dashboard/rooms List all active rooms with basic stats
  • GET /dashboard/rooms/:roomId Detailed room inspection with peers and media

📊 Analytics APIs

  • GET /analytics/server Server statistics and performance metrics
  • GET /analytics/rooms/:roomId/producers Producer statistics for specific room
  • GET /analytics/rooms/:roomId/consumers Consumer statistics for specific room

🏠 Room Management APIs

  • GET /rooms/:roomId Get room RTP capabilities
  • POST /rooms/:roomId/webrtc-transports Create WebRTC transport
  • POST /rooms/:roomId/join Join room as peer
  • POST /rooms/:roomId/leave Leave room

🎥 Media Management APIs

  • POST /rooms/:roomId/produce Start producing media (audio/video)
  • POST /rooms/:roomId/consume Start consuming media from peers
  • POST /rooms/:roomId/pause-producer Pause media producer
  • POST /rooms/:roomId/resume-producer Resume media producer
